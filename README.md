# 害虫识别系统项目报告

## 1. 项目概述

本项目是一个基于深度学习的害虫识别系统，集成了102类害虫检测模型和8类害虫类别（按作物分类）模型，实现了两阶段级联推理架构，能够同时识别害虫类别和具体害虫，并验证二者的一致性。

## 3. 核心功能

### 3.1 级联推理架构

系统采用两阶段级联推理架构：

1. **第一阶段**：8类害虫类别模型对输入图像进行推理，输出害虫类别（如水稻害虫、玉米害虫等）及其置信度。
2. **第二阶段**：102类害虫模型对同一图像进行推理，输出具体的害虫种类及其置信度。
3. **结果融合**：系统根据害虫类别对害虫检测结果进行过滤，验证检测到的害虫是否属于该类别。

### 3.2 主要功能模块

#### 3.2.1 模型服务（ModelService）

核心类，负责模型加载、推理和结果处理：

- **模型加载**：加载102类和8类模型
- **害虫类别预测**：使用8类模型预测害虫类别
- **害虫检测**：使用102类模型检测具体害虫
- **一致性检查**：验证检测到的害虫是否属于预测的类别
- **实时帧检测**：处理摄像头实时帧，显示检测结果

#### 3.2.2 前端界面（MainWindow）

用户交互界面，包含：

- **左侧操作面板**：选择图片、开始检测、实时检测、历史记录按钮，以及级联推理模式开关
- **中间图片显示区域**：显示原始图片或检测结果
- **右侧结果显示区域**：统计卡片、级联推理信息栏、结果标签页
- **级联推理信息**：显示害虫类别、置信度、最佳匹配和一致性
- **历史记录**：查看和管理检测历史

#### 3.2.3 历史记录窗口（HistoryWindow）

管理和查看检测历史：

- **历史记录列表**：显示所有检测记录
- **详细信息**：查看每条记录的详细信息，包括图片名称、检测时间、目标数量和检测结果

### 4.1 级联推理实现

def detect_image(self, image_path, conf_threshold=0.25):
    # 1. 害虫类别检测（8类模型）
    pest_category, category_conf = self.predict_pest_category(image_path)
    
    # 2. 害虫检测（102类模型）
    results = self.model(image_path, conf=conf_threshold)
    
    # 3. 结果处理和一致性检查
    filtered_pests = []  # 属于预测类别的害虫
    other_pests = []     # 不属于预测类别的害虫
    has_consistent_pest = False
    
    if self.use_cascade and pest_category:
        for pest in detections:
            if pest_category in self.pest_category_map:
                if pest['class_name'] in self.pest_category_map[pest_category]:
                    filtered_pests.append(pest)
                    has_consistent_pest = True
                else:
                    other_pests.append(pest)
            else:
                other_pests.append(pest)
```

def detect_camera_frame(self, frame):
    # 害虫类别检测
    pest_category, category_conf = self.predict_pest_category(frame)
    
    # 害虫检测
    results = self.model(frame, conf=0.25, verbose=False)
    annotated_frame = results[0].plot()
    
    # 绘制害虫类别信息
    if self.use_cascade and pest_category:
        category_text = f"{pest_category}"
        confidence_text = f"Confidence: {category_conf:.2f}"
        cv2.putText(annotated_frame, category_text, (10, 30),
                    cv2.FONT_HERSHEY_SIMPLEX, 0.8, (0, 255, 0), 2)
        cv2.putText(annotated_frame, confidence_text, (10, 60),
                    cv2.FONT_HERSHEY_SIMPLEX, 0.6, (0, 255, 0), 2)
    
    # 检查一致性并显示警告
    if not has_consistent_pest and detections:
        warning_text = "⚠️ Inconsistent: Pest does not match category"
        cv2.putText(annotated_frame, warning_text, (10, 145),
                    cv2.FONT_HERSHEY_SIMPLEX, 0.6, (0, 0, 255), 2)
```

## 6. 功能特点

1. **级联推理**：先检测害虫类别，再检测具体害虫，最后验证一致性，提高识别准确率
2. **实时检测**：支持摄像头实时检测，显示实时结果
3. **历史记录**：保存检测历史，支持查看详细信息
4. **资源监控**：实时监控CPU、内存和GPU使用情况
5. **用户友好**：直观的界面设计，清晰的结果展示
6. **可扩展性**：支持添加新的模型和功能
