# 害虫识别系统 - 项目报告

## 1. 项目简介

**项目名称**：害虫识别系统 (Pest Identification System)

**项目类型**：桌面应用程序

**技术栈**：
- 前端：PyQt5
- 后端：Python 3
- 数据库：SQLite3
- AI模型：YOLOv8
- 工具库：OpenCV、psutil、ultralytics

**功能定位**：基于深度学习的农业害虫识别系统，支持图片检测和实时摄像头检测，为农业生产和害虫防治提供技术支持。

## 2. 目录结构

```
pestsysytem/
```

## 3. 核心功能模块

### 3.1 登录注册系统

**功能描述**：
- 用户注册：创建新用户账号，包含用户名、密码验证
- 用户登录：验证用户身份，进入系统主界面
- 注册后返回登录：注册成功后自动关闭注册窗口并显示登录窗口

**技术实现**：
- 使用PyQt5构建图形界面
- SQLite3数据库存储用户信息
- 信号槽机制实现窗口间通信
- 固定窗口尺寸（520x680），使用背景图片和图标

**关键代码**：
- `LoginWindow`类：处理登录逻辑和界面
- `RegisterWindow`类：处理注册逻辑和界面
- 数据库操作：`register_user`和`login_user`方法

### 3.2 害虫检测系统

**功能描述**：
- 图片检测：上传图片进行害虫识别
- 实时摄像头检测：通过摄像头实时识别害虫
- 检测结果显示：展示检测到的害虫种类和置信度
- 结果保存：将检测结果保存到数据库和本地文件

**技术实现**：
- YOLOv8深度学习模型
- OpenCV处理图像和摄像头
- 后台线程进行实时检测
- 每3帧处理一次以优化CPU使用

**关键代码**：
- `ModelService`类：封装YOLOv8模型
- `detect_image`方法：处理图片检测
- `detect_camera_frame`方法：处理摄像头帧检测
- `update_camera_frame`方法：实时更新摄像头画面

### 3.3 历史记录管理

**功能描述**：
- 历史记录查询：查看用户的检测历史
- 记录搜索：按关键词和时间搜索历史记录
- 记录删除：删除单条或清空所有历史记录
- 数据导出：将历史记录导出为CSV格式

**技术实现**：
- SQLite3数据库存储历史记录
- QTableWidget展示历史数据
- 信号槽机制处理删除操作
- CSV模块实现数据导出

**关键代码**：
- `HistoryWindow`类：历史记录界面
- `get_user_history`方法：获取历史记录
- `delete_history_record`方法：删除单条记录
- `clear_user_history`方法：清空所有记录

### 3.4 资源监控系统

**功能描述**：
- CPU监控：实时监控CPU使用率
- 内存监控：实时监控内存使用情况
- GPU监控：实时监控GPU显存使用
- 状态栏显示：在主窗口状态栏显示资源占用

**技术实现**：
- psutil库获取系统资源信息
- 后台线程进行监控
- 历史数据记录和统计
- 定时更新状态栏信息

**关键代码**：
- `ResourceMonitor`类：资源监控功能
- `_monitor_loop`方法：后台监控循环
- `get_current_stats`方法：获取当前资源状态
- `update_status_bar`方法：更新状态栏显示

  - image_path (TEXT)

**数据操作**：
- 参数化查询防止SQL注入

## 8. 使用指南

### 8.1 环境配置

**依赖项**：
- Python 3.8+
- PyQt5
- OpenCV
- psutil
- ultralytics (YOLOv8)
- SQLite3

**安装步骤**：
1. 克隆项目代码
2. 安装依赖：`pip install -r requirements.txt`
3. 放置YOLOv8模型文件到`models/best1.pt`
4. 运行主程序：`python main.py`

### 8.2 操作流程

**登录注册**：
1. 打开程序，进入登录界面
2. 输入用户名和密码登录
3. 如无账号，点击"CREATE ACCOUNT"注册

**图片检测**：
1. 登录后进入主界面
2. 点击"Select Image"选择图片
3. 点击"Start Detection"开始检测
4. 查看右侧结果面板的检测结果

**实时检测**：
1. 点击"Real-time Detection"启动摄像头
2. 摄像头画面会实时显示在中间面板
3. 检测结果会实时更新在右侧面板
4. 再次点击按钮停止检测

**历史记录**：
1. 点击"History Records"打开历史记录窗口
2. 查看历史检测记录
3. 使用搜索框搜索特定记录
4. 点击"Delete"删除单条记录
5. 点击"Clear All"清空所有记录
6. 点击"Export"导出记录为CSV
